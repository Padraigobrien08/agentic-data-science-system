# Code of Conduct

## Our standard

This project expects respectful, direct, technically serious collaboration.

Examples of good behavior:

- assuming good intent
- giving concrete technical feedback
- challenging ideas without attacking people
- documenting tradeoffs clearly
- helping keep the repo trustworthy for users and contributors

Examples of unacceptable behavior:

- harassment or personal attacks
- dismissive or insulting language
- deliberately disruptive behavior
- publishing private information without permission
- bad-faith technical sabotage or misrepresentation

## Enforcement

Project maintainers may remove comments, issues, pull requests, or access that violate this standard.

## Scope

This applies in:

- GitHub issues
- pull requests
- discussions
- review comments
- other project communication spaces tied to this repository

## Reporting

If someone’s behavior makes the project unsafe or unproductive, report it privately to the maintainer.
