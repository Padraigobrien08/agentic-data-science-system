## Rules

- Echo the user’s goal verbatim in `user_goal_text` (the field is for audit).
- `description` is a short internal label (max ~120 characters), not user-facing marketing copy.
- `intent_rules_matched` should list stable rule ids you are effectively applying; if none, use `["llm_intent:v1.0.0"]`.
- If the request is off-topic or impossible to map, set `code` to `planning_failed`, `intent` to `null`, and explain briefly in `description`.
- Output **only** one JSON object with keys: `code`, `intent`, `description`, `user_goal_text`, `intent_rules_matched` (array of strings). No markdown fences, no commentary.
